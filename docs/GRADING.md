# Проверка перед защитой

Эта таблица связывает реализацию с пунктами присланной шкалы. Она не заменяет проверку правил на примерах, реальные партии против человека и объяснение алгоритма обоими участниками.

| Пункт | Где реализовано / что показать |
| --- | --- |
| Репозиторий и Makefile | Сборка из свежего клона; `make`, повторный `make`, `clean`, `fclean`, `re` |
| Правила | `game.cpp`, проверки захватов во всех направлениях, двойных троек, пяти и более, защитного захвата пятёрки |
| Интерфейс и таймер | Режимы 1–3, подсказка H, изменяющийся AI time; ncurses разрешён заданием |
| Улучшенный Minimax | `ai.cpp`: Negamax, alpha-beta, итеративное углубление, таблица транспозиций |
| Фактическая глубина | Completed depth показывает завершённую итерацию; выборочная ширина описана в README |
| Несколько окон поиска | `State::candidates()`: объединение квадратов 5×5 вокруг отдельных камней с удалением повторов |
| Alignments | `evaluation.cpp`: непрерывные и разорванные линии обоих цветов |
| Potential win by alignment | `roomForFive()`: минимум пять доступных пересечений вдоль оси |
| Freedom | Разные веса при двух, одном и нуле свободных концов |
| Potential captures | `inspect()`: цели захвата, несколько пар одной целью, приближение к десяти захваченным камням |
| Captures | Отдельный компонент: 1 600 за уже захваченный камень |
| Figures | Пересекающиеся четвёрки, четвёрка + тройка, две тройки, совмещение захвата и развития линии |
| Players | Все статические и динамические компоненты отдельно для двух цветов; итог — разность с точки зрения игрока, которому ходить |
| Dynamic part | `historyProfile()` анализирует последовательность реальных действий; повторения направлений и захваты меняют вес позиций |
| Bonuses | Pro/Swap/Swap2, выбор правил, сохранение/загрузка, просмотр истории, undo, ИИ против ИИ; решение о раздельном зачёте принимает проверяющий |

## Команды

```sh
make -j
make test
make sanitize
make ui-test
./Gomoku --bench
```

В игре нажмите `V`, чтобы показать компоненты оценки для X/O. Таймер остаётся на экране. Тесты содержат позиции без места для пятёрки, все направления захвата и блокировки, разорванную четвёрку, победу несколькими захватами, защитную опору для будущего захвата и две разные истории, ведущие к одинаковой доске. Сохранение/загрузка и отмена действий проверяются вместе с профилем истории.

## Что ещё оценивается вручную

- Сила ИИ определяется партиями против человека, который пытается выиграть. Тактические тесты и самоигра не гарантируют результат по шкале 0–5.
- Измеряйте время на компьютере защиты и на разных стадиях партии. Бюджет 420 мс не является гарантией жёсткого времени ОС.
- Глубина ограничена временем и выбором кандидатов; десять уровней не гарантируются для любой позиции. Немедленная победа или доказанный проигрыш могут завершить поиск раньше.
- Оба участника должны объяснить отсечения, эвристику, профиль истории и ограничения выборочного поиска.
- Бонусы оцениваются после прохождения обязательной части. Количество зачтённых бонусов заранее не гарантируется.

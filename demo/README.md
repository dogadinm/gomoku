# Позиции для показа правил

Каждое сохранение показывает одно правило задания. Позиции строит `make demo` настоящими ходами; та же программа проверяет, что показываемый ход даёт описанный результат.

## Как открыть

```sh
make
./demo/play.sh 03
```

В меню нажмите `2` (два человека), затем `L` — загрузится позиция. Стрелками или мышью выберите клетку, `Space` — ход. Клетки обозначены как на доске: буква столбца, номер строки.

| № | Правило | Ход | Что видно |
| --- | --- | --- | --- |
| 01 | Захват во всех восьми направлениях | X: **J10** | Снимаются 8 пар белых, `Captured X: 16`. В этой позиции запрет двойной тройки выключен — кольцо камней не про него |
| 02 | Ход в «окружение» не является захватом | O: **K10** | Пара белых J10–K10 между чёрными остаётся на доске |
| 03 | Двойная открытая тройка запрещена (пример из задания) | X: **E5** | `Illegal move … double-three`, камень не ставится |
| 04 | Закрытая тройка не считается: камень O в D5 | X: **E5** | Ход разрешён |
| 05 | Двойная тройка, созданная захватом, разрешена | X: **E5** | Ход разрешён, снимается пара E6–E7, `Captured X: 2` |
| 06 | Пятёрку можно разбить захватом | X: **J10**, затем O: **H9** | После J10: `Five! Capture to defend.` O захватывает H10–H11 — пятёрка разрушена, игра продолжается |
| 07 | Пять **или больше** подряд выигрывают | X: **H10** | Шесть в ряд, `Winner: Black` |
| 08 | Десять захваченных камней — победа | X: **L18** | Пятая пара J18–K18, `Captured X: 10`, `Winner: Black` |
| 09 | Пятёрка не выигрывает, если соперник может взять десятый камень | X: **J18**, затем O: **O11** | После J18 — `Five! Capture to defend.` O захватывает M11–N11, у белых 10 камней, `Winner: White` |

`U` отменяет ход, поэтому один и тот же показ можно повторить. `make demo` пересоздаёт файлы и заново проверяет каждое правило.
